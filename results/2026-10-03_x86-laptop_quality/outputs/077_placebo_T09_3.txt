    <section id="features">
      <h2>Features</h2>
      <ul class="feats">
        <li><h3>Semantic diff</h3><p>Compares parsed values, not text. Reordered keys and comment edits never show up as noise.</p></li>
        <li><h3>Secret-safe</h3><p>Values that look like tokens or keys are masked in every output, including CI logs and JSON reports.</p></li>
        <li><h3>Schema checks</h3><p>Validate each environment against a JSON Schema and fail the build on missing or mistyped keys.</p></li>
        <li><h3>Promote</h3><p>Apply a reviewed diff from one environment to another, with a dry run by default and a patch file you can commit.</p></li>
        <li><h3>CI native</h3><p>Stable exit codes, GitHub annotations and SARIF output. No network access, no telemetry.</p></li>
      </ul>
    </section>

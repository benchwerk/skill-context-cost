<section id="what"><div class="wrap">
  <h2>What it does</h2>
  <div>
    <pre class="demo"><span class="c"># replace every console.log(x) with logger.debug(x), only in call position</span>
$ sift rewrite <span class="a">'console.log($A)'</span> <span class="a">'logger.debug($A)'</span> src/
<span class="d">- </span>console.log(user, "signed in")
<span class="a">+ </span>logger.debug(user, "signed in")
<span class="c">14 matches in 6 files · strings and comments untouched · 38ms</span></pre>
    <p class="lede">Write a pattern as ordinary code with <code>$VARS</code> as holes. sift parses both sides, matches on structure, and previews every change as a diff before touching a file.</p>
  </div>
</div></section>

<section id="features"><div class="wrap">
  <h2>Features</h2>
  <ol class="features">
    <li><h3>Structural patterns</h3><p>Match calls, imports, and blocks regardless of whitespace, line breaks, or argument names.</p></li>
    <li><h3>Diff-first rewrites</h3><p>Nothing is written until you pass <code>--apply</code>. Review, then commit or discard.</p></li>
    <li><h3>Thirty languages</h3><p>Grammars are bundled. Mixed repositories work in a single pass.</p></li>
    <li><h3>Fast on large trees</h3><p>Parallel parsing respects <code>.gitignore</code>. A million-line monorepo scans in about a second.</p></li>
    <li><h3>Rules as files</h3><p>Save patterns to <code>sift.yml</code> and run them in CI to keep deprecated APIs out.</p></li>
    <li><h3>Editor friendly</h3><p>Emits JSON or SARIF, so results show up inline in your editor and code review.</p></li>
  </ol>
</div></section>
